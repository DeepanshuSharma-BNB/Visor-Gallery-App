# Visor Gallery

Personal photo viewer for Meta Ray-Ban Display, hosted by GitHub Pages.

- Phone: https://deepanshusharma-bnb.github.io/Visor-Gallery-App/phone.html
- Glasses: https://deepanshusharma-bnb.github.io/Visor-Gallery-App/glasses.html

Select images on your phone, pair with the code displayed in the glasses, and browse using the Neural Band. Experimental public relay: avoid sensitive pictures.
